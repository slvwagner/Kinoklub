\section{Kinoklub}\label{kinoklub}

Shiny app zur Abrechnung für den Kinoklub TaB. Um die Abrechnung für den
Kinoklub zu vereinfachen respektive zu automatisieren wurde dieser
Script erstellt.\\
\strut \\
Bei Fehlern kann ein ``Issue'' in Github erfasst werden.\\
\url{https://github.com/slvwagner/Kinoklub/issues}\strut \\

\section{Installation}\label{installation}

\subsection{Anleitung}\label{anleitung}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\item
  Download und instalieren von R\\
  \url{https://cran.r-project.org/bin/windows/base/}
\item
  Download und instalieren Rstudio\\
  \url{https://posit.co/download/rstudio-desktop/}
\item
  Download und instalieren Git\\
  \url{https://git-scm.com/downloads}
\item
  Projekt herunterladen:\\
  Erstelle ein Ordner wo die Dateien abgespeicher werden sollen.\\
  Ein Terminal öffnen (in Windows: rechte Maustaste und dann Terminal
  öffnen) und dann folgenden code ausführen.

\begin{verbatim}
    git clone https://github.com/slvwagner/Kinoklub
\end{verbatim}
\item
  Start Rstudio vom Kinoklub Ordner und dann das Projekt
  ``Kinoklub.Rproj'' öffnen.
\item
  Installieren der benötigten ``Packages'' im ``R Terminal''

\begin{verbatim}
## install.packages("rsconnect","rmarkdown","tidyverse","knitr","lubridate","renv","base","colorspace","dplyr","DT","openxlsx","readr","shiny","shinyjs","shinyTime","stringr","tibble","viridis","furrr","future","parallel","processx","tools","utils","DBI","rebus","curl","httr","purrr","rvest","RPostgres","ggplot2","plotly","hms","RMySQL")
\end{verbatim}
\item
  Benutzer and Passwörter auf dem lokalen Computer Einrichten:\\

  \begin{itemize}
  \item
    Windows\\
    Terminal Kommandos nacheinander mit den korrekten Daten ausführen:

\begin{verbatim}
setx DB_host "your host name here"
\end{verbatim}

\begin{verbatim}
setx DB_name "your database name here"
\end{verbatim}

\begin{verbatim}

\end{verbatim}

\begin{verbatim}

\begin{verbatim}

  \item
    MAC / Linux\\
    Erstellen ein neue Datei \textbf{``.Renviron''} im Kinoklub
    Benutzerverzeichniss.\\
    Die Datei wie folgt abfüllen:\\

\begin{verbatim}

\subsection{Git Passwort / Personal Access Token
(PAT)}\label{git-passwort-personal-access-token-pat}

Git Passwort gibt es seit 2021 nicht mehr. Um sich bei Git anzumelden,
muss man auf der GitHub Webseite unter dem eigenen Profil in den
Einstellungen auf \textbf{Developer Settings} navigieren. Dann unter
\textbf{Personal access tokens} \textbf{Tokens (classic)} anwählen. Oben
rechts auf \textbf{Generate new token} klicken und \textbf{classic}
auswählen. Dem Token einen Namen geben und \textbf{Expiration} auf
\textbf{No Expiration} setzen. Danach alle \textbf{repo} anwählen. Nach
unten scrollen und Token generieren. Token kopieren und Anleitung unten
im Bild folgen.\\

Neue Dateien können mittels ``Drag \& Drop'' oder Auswahl einer Datei
hochgeladen werden.\\
Dateien werden automatisch im korrekten Verzeichniss anhand des
Dateinamens und der Dateierweiterung abgespeichert.

\begin{itemize}
\tightlist
\item
  ``Eintritt ID???.txt'' Dateien werden im Verzeichniss
  ``\ldots/Kinoklub/Input/advance tickets/'' gespeichert.
\item
  ``Kiosk ID???.txt'' Dateien werden im Verzeichniss
  ``\ldots/Kinoklub/Input/advance tickets/'' gespeichert.
\item
  ``procinema.txt'' Dateien werden im Verzeichniss
  ``\ldots/Kinoklub/Input/Procinema/'' gespeichert.
\item
  ``csv'' Dateien werden im Verzeichniss
  ``\ldots/Kinoklub/Input/Wordpress'' gespeichert.
\end{itemize}

Die Datensätze können von \url{https://www.advance-ticket.ch/admin}
heruntergeladen werden und und können mittels drag\&drop abgespeichert
werden. Die Dateien sind unter dem Verzeichnis
\textbf{\ldots/Kinoklub/input/advance tickets/} zu finden.

\textbf{Eintritte ID??.txt}\\
Copy paste von html für jede Vorführung, die \textbf{``Event ID''} ist
dem Programm zu entnehmen: Bitte speichern unter ``input/advance
tickets/Eintritt ID???.txt'' oder über GUI hochladen. Es muss die

abspeichern(``input/advance tickets/Eintritt xxxx.xxx xx.xx.xx.txt'')
oder über GUI hochladen.

\subsection{Inputdaten}\label{inputdaten}

\subsubsection{Filmvorschlag}\label{filmvorschlag}

Ein Filmvorschlag kann am einfachsten mit dem Feature
``Procinema-Suche'' erfasst werden falls die Suisanummer bekannt ist.
Die Suisanummer wird auf Procinemagesucht und das Suchresultat kann
direkt übernommen werden.

\subsubsection{Programm}\label{programm}

\begin{itemize}
\tightlist
\item
  Für jeden gezeigten Film muss ein Datum und einen Zeit definiert
  werde.
\item
  Für jeden gezeigzen Film muss eine Suisanummer definiert sein.
\item
  Ist kein Suisanummer vorhanden z.B. weil es nur einen Ausländischen
  verleiher gibt kann die Suisanummer die von Advanced-Tickets erzeugt
  wird verwendet werden.
\item
  Mit der Spalte \textbf{``Link to Event ID''} ist es möglich gemeinsam
  mit weitere(n) ``Event ID(s)'' abzurechnen.\\
  Es wird nur noch für die erste \textbf{``Event ID''} ein Bericht
  erstellt. Es werden alle Einahmen und Ausgaben zusammengefasst für
  diesen Bericht.
\item
  Es muss der \textbf{``minimal Abzug {[}CHF{]}''} sowie \textbf{``Abzug
  \%''} oder nur der \textbf{``Abzug fix {[}CHF{]}''} definiert werden.
  Beide Einträge sind nicht erlaubt.
\item
  In der Tabelle Dropdowns Verleiher Spalte \textbf{Kinoförderer gratis}
  muss für jeden Verleiher definiert werden, ob gewisse Platzkategorien
  (z.B.Kinoförderer Tickets) als gratis abgerechnet werden dürfen.\\
  Wenn \textbf{nein} gewählt wird, dann wird die Platzkategorie
  \textbf{Kinoförderer} als Platzkategorie ``Ermässigt'' verrechnet.\\
  Der Rechnungsbetrag der Verleiherrechnung an den Kinoklub wird demnach
  grösser.
\end{itemize}

\subsubsection{Einsatzplan}\label{einsatzplan}

Im Einsatzplan wird die Ressourcenplanung vorgenommen.
Kinoklubmitglieder können sich selbständig eintragen. Welche Funktion
die Kinoklubmitglieder belegen dürfen ist in der Tabelle Dropdowns
Kinoklubmitglieder definiert.

\subsubsection{Einnahmen}\label{einnahmen}

Alle Einnahmen müssen in der Tabelle \textbf{Einnahmen} definiert
werden. Ja nach \textbf{Einnahmentyp} muss die richtige
\textbf{Kategorie sowie Buchungskonto} verwendet werden. Das ist nötig
um die Einnahmen korrekt in den \textbf{Berichten} auszuwerten.\\
In der Tabelle \textbf{Einnahmen} werden alle Einnahmen erfasst, die
nicht automatisch aus den Advaced Tickets Daten extrahiert werden
können.

\begin{itemize}
\tightlist
\item
  Erklärung der \textbf{Spaltennamen}

  \begin{itemize}
  \tightlist
  \item
    \textbf{ID}\\
    Fortlaufendenummer (automatisch erzeugt)
  \item
    \textbf{Kategorie}\\
    Die Kategorie muss korrekt ausgewählt werden. Hier eine kurze
    Erklärung aller Optionen:

    \begin{itemize}
    \tightlist
    \item
      Event\\
      Die Kategorie Event wird in der Abrechnung (Abrechnung pro Film)
      aufgeführt. Als \textbf{Ausgaben} können dies Spezielle
      Verkaufsartikel (Gipfeli), Materialmiete für diesen Anlass,
      Event-Deko oder andere Ausgaben sein.\\
      WICHTIG: Hier muss die korrekte \textbf{Event ID} angegeben
      werden.
    \item
      Kiosk\\
      Ausgaben für den Einkauf des Kino-Kiosks
    \item
      Personalaufwand\\
      Ausgaben für Gehaltszahlung and Mitarbeiter
    \item
      Verleiher\\
      Rechnungen vom Filmverleiher\\
      WICHTIG: Hier muss die korrekte \textbf{Event ID} angegeben
      werden.
    \item
      Vermietung\\
      Einnahmen durch die Vermietung
    \item
      Werbung\\
      Werbeeinnahmen z.B. Kinoweischer
    \item
      Sonstiges\\
      Alle Einnahmen die nicht auf eine spezifische Kategorie zugewiesen
      werden können.\\
    \end{itemize}
  \item
    \textbf{Bezeichnung}\\
    Umschreibung der Buchung
  \item
    \textbf{Event ID}\\
    Zu welcher Filmvorführung gehört diese Buchung?\\
    Das ist wichtig für die Kategorie Event und Verleiher, siehe oben.
  \item
    \textbf{Datum}\\
    Buchungsdatum
  \item
    \textbf{Abrechnungsjahr}\\
    In welche Abrechnungsperiode (Jahr) wird die Buchung zugewiesen?
  \item
    \textbf{Betrag}\\
    Betrag in {[}CHF{]}
  \item
    \textbf{Firmenname}\\
    Name der rechnugsstellenden Firma oder oder Person and die der
    Betrag ausbezahlt werden muss.
  \item
    \textbf{Adresse}\\
    Rechnungsteller
  \item
    \textbf{Rechnungsnummer}\\
    Rechnungsnummer des Rechnungsstellers
  \item
    \textbf{Buchungskonto}\\
    Buchungskonto in Bexio (Buchhaltungstool TaB), muss Geschäftsleitung
    weitergegeben werden um Buchung
  \end{itemize}
\item
  In der Tabelle \textbf{Kategorien} sind die möglichen Kategorien
  definiert. Notwendige Änderungen müssen zuerst besprochen werden,
  ansonsten kann es sein, dass das R-Tool nicht mehr funktioniert.
\end{itemize}

\subsubsection{Ausgaben}\label{ausgaben}

Alle Ausgaben müssen in der Tabelle \textbf{Ausgaben} definiert
werden.\\
Ja nach \textbf{Ausgabentyp} muss eine \textbf{Kategorie,
(Buchhaltungskonto)} verwendet werden. Das ist nötig um die Einnahmen
und Ausgaben korrekt in den \textbf{Berichten} auszuwerten.\\
In der Tabelle \textbf{Ausgaben} werden alle Ausgaben verbucht die nicht
automatisch aus den Advanced Tickets Daten extrahiert werden können.

\begin{itemize}
\tightlist
\item
  Erklärung der \textbf{Spaltennamen}

  \begin{itemize}
  \tightlist
  \item
    \textbf{ID}\\
    Fortlaufendenummer (automatisch erzeugt)
  \item
    \textbf{Kategorie}\\
    Die Kategorie muss korrekt ausgewählt werden. Hier eine kurze
    Erklärung aller Optionen:

    \begin{itemize}
    \tightlist
    \item
      \textbf{Event}\\
      Die Kategorie Event wird in der Abrechnung (Abrechnung pro Film)
      aufgeführt. Als \textbf{Einnahmen} können Kollekten, Beiträge von
      Veranstallter oder sonstige Einnahmen sein. Diese Einnahmen müssen
      sich auf eine spezifische Filmvorführung beziehen somit muss
      Spieldatum und Suisanummer korrekt angegeben werden.
    \item
      \textbf{Kiosk}\\
      Ausgaben für den Einkauf des Kino-Kiosks
    \item
      \textbf{Personalaufwand}\\
      Ausgaben für Gehaltszahlung and Mitarbeiter
    \item
      \textbf{Sonstiges}\\
      Alle Kosten die nicht auf eine spezifische Kategorie zugewiesen
      werden können.
    \item
      \textbf{Verleiher}\\
      Ausgaben: Rechnungen vom Filmverleiher WICHTIG: hier muss das
      Spieldatum des Filmes eingetragen werden, damit die Abrechnung
      korrekt abläuft
    \item
      \textbf{Vermietung}\\
      Ausgaben oder Einnahhmen die für einen Vermietung getätigt werden.
    \item
      \textbf{Werbung}\\
      Allgemeine Werbekosten die nicht auf eine Filmvorführung abgewälzt
      werden können
    \end{itemize}
  \item
    \textbf{Event ID}\\
    Wird die Kategorie Event oder Verleiher ausgewählt muss hier die
    \textbf{``Event ID''} des Films dazugehörigen Films eingetragen
    werden, damit die Ausgaben auf der Filmabrechnung ausgewiesen
    werden. Bei Ausgaben die sich nicht auf ein spezifische
    \textbf{``Event ID''} beziehen, muss dieses Feld leer gelassen
    werden. Diese Ausgaben werden nur in der Jahresabrechnung
    berücksichtigt.\\
  \item
    \textbf{Bezeichnung}\\
    Umschreibung der Buchung
  \item
    \textbf{Datum}\\
    Datum der Rechnung/Buchung.
  \item
    \textbf{Abrechnungsjahr}\\
    In welche Abrechnungsperiode (Jahr) wird die Buchung zugewiesen?
  \item
    \textbf{Betrag}\\
    Betrag {[}CHF{]}
  \item
    \textbf{Firmenname}\\
    Firmenname oder Person des Rechnungstellers an welchen der
    \textbf{Betrag} ausbezahlt werden muss.
  \item
    \textbf{Adresse}\\
    Rechnungsteller
  \item
    \textbf{Referenz}\\
    Referenznummer der Rechnung
  \item
    \textbf{Rechnungsnummer}\\
    Rechnungsnummer des Rechnungsstellers
  \item
    \textbf{Buchungskonto}\\
    Buchungskonto in Bexio (Buchhaltungstool TaB), muss Geschäftsleitung
    weitergegeben werden um Buchung korrekt durchzuführen.
  \end{itemize}
\end{itemize}

\subsubsection{Einkauf Kiosk}\label{einkauf-kiosk}

In der Tabelle \textbf{Einkauf Kiosk} werden die aktuellen
Einkaufspreise definiert um den Gewinn für einen Kioskverkaufsartikel zu
ermittel.\\
Der Einkaufspreise ist gültig ab dem Datum in der Spalte ``Gültig ab
Datum'' .\\
Die Einkaufspreise für die Kioskverkäufe müssen gepflegt werden. Ändern

gemacht werden. Der alte soll nicht gelöscht werden da sich die
Einkaufpreise über die Zeit ändern können wird immer der korrekte
Einkaufspreis gesucht und für die Gewinn berechnung verwendet.\\
